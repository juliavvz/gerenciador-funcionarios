# Gerenciador de Funcionários

Programa em C++ para administrar uma lista de funcionários com as funcionalidades:
- Incluir funcionário (sem duplicação de prontuário)
- Excluir funcionário
- Pesquisar por prontuário
- Listar todos com total de salários

## Como compilar
```bash
g++ main.cpp -o funcionarios
```

Como executar

```bash
./funcionarios
```
